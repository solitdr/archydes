# Contributing

Thank you for helping. Issues and pull requests are welcome.

- **Specification:** report unclear or contradictory passages as an issue, with the section
  number (for example A9). Changes to the format itself are decided by SOLIT SRL; new
  identifiers keep old archives readable (SPEC A2).
- **Code:** please run `cargo test --release --workspace --locked` and
  `python3 testvectors/check.py` before sending a pull request. Keep dependencies few and under
  permissive licenses (MIT, Apache-2.0, BSD, zlib, 0BSD, CC0 and the like). GPL and LGPL code is
  not accepted.
- **Other implementations:** tell us about yours; we are happy to link it.

Contributions are accepted under the licenses of this repository (MIT OR Apache-2.0 for code,
CC BY 4.0 for the specification), without a separate agreement.
